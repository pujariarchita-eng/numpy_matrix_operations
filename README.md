NumPy Matrix Operations

Project Overview

This project demonstrates basic matrix operations using Python and NumPy. Two matrices are created, and various mathematical operations are performed on them.

Objectives

* Create two matrices using NumPy.
* Perform matrix addition.
* Perform matrix subtraction.
* Perform matrix multiplication.
* Perform matrix transpose.

Technologies Used

* Python
* NumPy
* Jupyter Notebook / Google Colab

Operations Performed

1. Matrix Addition: Adds corresponding elements of two matrices.
2. Matrix Subtraction: Subtracts corresponding elements of two matrices.
3. Matrix Multiplication: Multiplies two matrices using NumPy.
4. Matrix Transpose: Converts rows into columns and columns into rows.

Project Files

* numpy_matrix_operations.ipynb – Jupyter Notebook containing the Python code and output.
* README.md – Project documentation.

How to Run

1. Download or clone this repository.
2. Open the notebook in Jupyter Notebook or Google Colab.
3. Ensure NumPy is installed.
4. Run all the cells to view the results.

Installation

pip install numpy

Applications

NumPy matrix operations are commonly used in numerical computing, data analysis, scientific computing, and machine learning.
